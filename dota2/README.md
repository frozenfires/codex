# Dota 2 12v12

目标：24 名玩家，天辉、夜魇各 12 人；地图、英雄、装备、兵线、野区、经济、升级、复活及摧毁远古遗迹的胜利条件尽量沿用当前版本标准 Dota 2。

## 当前实现

- `game/addoninfo.txt` 声明 24 人容量，并指定内置地图 `dota`。
- `game/scripts/vscripts/addon_game_mode.lua` 将天辉、夜魇容量设为各 12 人，关闭其他队伍。
- 没有添加自定义英雄、物品或数值调整。上述容量设置不保证引擎自动启用全部标准比赛逻辑。

这是尚待游戏内验证的项目骨架，不是已经完成的可发布地图。当前没有地图源文件，也没有在 Dota 2 客户端验证内置 `dota` 地图能否由该 addon 直接加载。若当前工具版本不支持，需要通过 Workshop Tools 准备适用的地图资源；不要把一张空白地图当作标准地图。

## 本地安装与启动

需要 Windows 上的 Dota 2、Steam 中安装的 Dota 2 Workshop Tools，以及启用开发者控制台的游戏客户端。Linux 云环境用于编辑脚本，不能替代客户端验收。

1. 在 Workshop Tools 中创建名为 `dota_12v12` 的 addon，保留工具生成的项目和 content 目录。
2. 将本仓库 `game/` 下的文件合并到 `<SteamLibrary>/steamapps/common/dota 2 beta/game/dota_addons/dota_12v12/`。替换已有文件前先备份；不要覆盖其他项目。
3. 从工具启动该 addon，在开发者控制台执行 `dota_launch_custom_game dota_12v12 dota`。
4. 检查控制台没有地图缺失、Lua API 或脚本加载错误。确认脚本实际加载，再进行下列验收。

## 必须完成的游戏内验收

- 大厅允许 24 名真人加入，第 25 人无法占据玩家席位；天辉、夜魇各能分配 12 人，没有第三支队伍。
- 24 名玩家均能选英雄、进入比赛，在各自泉水附近出生并购买物品；确认镜头和英雄控制正常。机器人只能辅助测试，不能证明 24 名真人连接可用。
- 对比同版本标准比赛，确认地图布局、三路兵线、防御塔、泉水、商店、野怪、肉山、符点及地图目标正常。
- 确认金钱、经验、死亡复活、建筑保护、日夜循环及摧毁远古遗迹的胜负结算正常。
- 完成一次多人联机整局，并检查额外英雄对出生位置、单位寻路、性能和界面的影响。

若内置地图无法加载、24 人受到客户端限制，或标准规则没有自动运行，应先记录具体版本与错误，再补充相应地图资源或规则实现。本项目尚未通过以上验收，不能据此保证与官方比赛完全一致。
